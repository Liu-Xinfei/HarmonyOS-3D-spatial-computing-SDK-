# HarmonyOS-3D-spatial-computing-SDK-
面向 HarmonyOS NEXT的 3D 空间计算基础库，使用 ArkTS 原生开发，为增强现实、空间交互、物理模拟等场景提供完整的底层支撑。


核心能力
空间数学
提供完整的 3D 数学基础，包括三维向量（Vector3）、四元数（Quaternion）和 4×4 变换矩阵（Matrix4）。四元数采用 Hamilton 惯例，通过 SLERP 球面线性插值实现平滑旋转动画，彻底规避欧拉角的万向节死锁问题。Matrix4 支持透视/正交投影、TRS 分解、lookAt 视图矩阵等图形学常用运算。
几何查询
实现射线（Ray）、平面（Plane）、轴对齐包围盒（AABB）、球体（Sphere）和视锥体（Frustum）等基础几何体。射线与三角形求交采用 Möller-Trumbore 算法，AABB 相交检测使用 Slab 方法，视锥体裁剪直接从 VP 矩阵提取六个裁剪平面，可用于场景剔除加速渲染。
场景图
基于父子层级的场景树，每个节点（SceneNode）维护局部变换（Transform）并通过脏标记缓存世界矩阵，避免每帧重复计算。内置事件系统支持变换变化、节点挂载/卸载的回调通知。Camera 节点支持透视和正交双模式，可直接生成视锥体用于可见性裁剪。Light 节点支持方向光、点光源、聚光灯，点光源采用物理平滑衰减模型。
AR 空间感知
封装鸿蒙 AR Engine 的平面检测（PlaneDetector）和空间锚点（SpatialAnchor）能力。平面检测支持水平面、垂直面过滤，并提供多边形点包含测试（射线法）和面积计算。空间锚点带完整状态机（initializing / tracking / paused / stopped），支持跨会话序列化与恢复。SpatialHitTest 提供屏幕触摸到真实世界的射线命中测试，是 AR 家具摆放、空间标注等场景的核心接口。
物理模拟
轻量刚体动力学引擎，支持动态、运动学、静止三类刚体，碰撞形状覆盖球体、盒体、胶囊体。宽相使用 AABB 剔除，窄相实现球-球碰撞检测，响应采用冲量法并包含摩擦力模拟和穿透深度修正。固定步长积分（默认 60Hz）配合最大子步数限制，保证帧率波动时物理稳定性。支持射线投射拾取刚体。

设计原则
纯 ArkTS 实现，无任何第三方依赖，完整符合 ArkTS 严格模式规范（无 any/unknown、无结构化类型、无解构赋值、无展开运算符）。
分层架构，数学层 → 几何层 → 场景层 → AR/Physics 层，各层单向依赖，可按需裁剪引入。
零运行时开销的缓存策略，Transform 使用脏标记延迟计算世界矩阵，Camera 的投影矩阵和视图矩阵按需重建，避免每帧无效计算。

适用场景

AR 家具/商品预览：平面检测 + 锚点 + 命中测试
空间标注与导航：场景图 + 世界坐标变换
3D UI 交互：射线拾取 + 视锥裁剪
虚实物理交互：刚体模拟 + AR 平面碰撞
多设备分布式空间共享：锚点序列化 + 跨会话恢复
